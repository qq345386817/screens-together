Help

Use one device as the host and the rest as display tiles. For best results, keep all devices on the same Wi-Fi network and arrange them before starting playback.

Set up a room

  1. Open ScreensTogether on the device that will control playback.
  2. Tap Host a Room, choose a layout, and set the message or video.
  3. Open ScreensTogether on each display device and tap Join as Display.
  4. Join the host room, then place each device in the physical order shown by its tile assignment.
  5. Use screen gap and crop offset controls on the host to fine-tune alignment.

Troubleshooting

  • If a room does not appear, confirm all devices are on the same local network and that Local Network permission is allowed.
  • If playback looks offset, restart playback from the host after every display has joined.
  • If a video tile is blank, import the video again and wait for the host to finish sending it to connected displays.
