A few things before you start.

Does it need an account or internet service?

Local rooms require no account or cloud service. Install the app on each device, keep devices nearby, and allow Local Network access. The same local Wi-Fi network is recommended; guest-network client isolation can prevent discovery.

Is this AirPlay or desktop mirroring?

No. ScreensTogether splits the selected text or video into assigned screen regions. It does not mirror the whole desktop, other apps, or protected streaming services.

Is playback perfectly frame-locked?

Playback is coordinated on a shared timeline, not guaranteed hardware frame lock. Timing depends on the devices, video, and network. Test and calibrate the actual setup before an event; layout limits are not a guarantee of tested simultaneous-device capacity.
