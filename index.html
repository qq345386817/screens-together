Built for fast temporary display walls.

ScreensTogether focuses on the job: arrange devices, assign tiles, and keep playback aligned. No account setup is required for the local room workflow.

Host controls the canvas

Choose text or video, set the layout, adjust screen gaps, and start playback from one host device.

Each device renders a tile

Joined displays receive an assignment and render only their part of the full shared picture.

Useful beyond demos

Make booth signs, classroom walls, table displays, window messages, and quick event visuals with devices already nearby.

One app, different device roles

Free app. Store availability is shown on the App Store listing.

iPhone / iPad

The iPhone or iPad host is one of the screens. Select 1 screen for local playback, or include every participating device in the total.

macOS

The native Mac Host Controller advertises a room automatically. Open File > New Window and choose Display Node in the second window to join it. For one joined display window, use a 1 x 1 layout. The controller window is not a display tile; each joined Display Node window is. Approve the join, then use Play in the controller's Live Controls. You can also join physical devices.

Apple TV

Apple TV is a display receiver, not a host. Keep a room open on iPhone, iPad, or Mac, join it from Apple TV, approve the request, and start playback on the host. With an iPhone or iPad plus Apple TV, select 2 screens. With a Mac controller and only Apple TV as a display, use 1 x 1.
