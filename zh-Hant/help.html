說明

使用一台裝置作為 Host，其餘裝置作為顯示 Tile。為了獲得更好效果，請讓所有裝置連接同一個 Wi-Fi，並在開始播放前擺好位置。

設定房間

  1. 在負責控制播放的裝置上開啟 ScreensTogether。
  2. 點一下 建立主控房間，選擇版面，並設定文字或影片。
  3. 在每台顯示裝置上開啟 ScreensTogether，然後點一下 作為顯示螢幕加入。
  4. 加入 Host 房間後，按照裝置的 Tile 編號擺放實體裝置。
  5. 在 Host 上使用螢幕間距和裁切偏移控制來微調對齊。

疑難排解

  • 如果房間沒有出現，請確認所有裝置在同一個本地網路，並允許本地網路權限。
  • 如果播放看起來不同步，請在所有顯示裝置加入後從 Host 重新開始播放。
  • 如果影片 Tile 是空白，請重新匯入影片，並等待 Host 完成傳送。
