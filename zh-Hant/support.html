支援

需要支援請寄信到 support@luopeike.com。請附上裝置型號、iOS 或 iPadOS 版本，以及問題發生在 Host 還是 Display 裝置上。

有幫助的資訊

  • Host 上選擇的版面，例如 1 x 2、1 x 3 或 2 x 2。
  • 所有裝置是否連接到同一個 Wi-Fi 網路。
  • Host 房間和 Display 分配畫面的截圖或短片。
