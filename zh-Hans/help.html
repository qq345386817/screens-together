帮助

使用一台设备作为 Host，其余设备作为显示 Tile。为了获得更好效果，请让所有设备连接同一个 Wi-Fi，并在开始播放前摆好位置。

设置房间

  1. 在负责控制播放的设备上打开 ScreensTogether。
  2. 点击 创建主控房间，选择布局，并设置文字或视频。
  3. 在每台显示设备上打开 ScreensTogether，然后点击 作为显示屏加入。
  4. 加入 Host 房间后，按照设备的 Tile 编号摆放实体设备。
  5. 在 Host 上使用屏幕间距和裁切偏移控制来微调对齐。

故障排查

  • 如果房间没有出现，请确认所有设备在同一个本地网络，并允许本地网络权限。
  • 如果播放看起来不同步，请在所有显示设备加入后从 Host 重新开始播放。
  • 如果视频 Tile 是空白，请重新导入视频，并等待 Host 完成发送。
