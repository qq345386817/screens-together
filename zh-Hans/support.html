支持

需要支持请发送邮件到 support@luopeike.com。请附上设备型号、iOS 或 iPadOS 版本，以及问题发生在 Host 还是 Display 设备上。

有帮助的信息

  • Host 上选择的布局，例如 1 x 2、1 x 3 或 2 x 2。
  • 所有设备是否连接到同一个 Wi-Fi 网络。
  • Host 房间和 Display 分配界面的截图或短视频。
