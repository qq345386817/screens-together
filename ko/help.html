도움말

ScreensTogether는 흐르는 문구나 로컬 비디오를 가까운 iPhone, iPad, Mac, Apple TV 화면에 나눠 표시합니다. 콘텐츠를 준비하고 화면을 연결해 위치를 배정한 뒤 재생하세요.

iPhone 또는 iPad를 호스트로 설정한 Mac에서 여러 창 사용Apple TV에서 참가질문과 문제 해결

iPhone 또는 iPad를 호스트로 설정

  1. Host a Room을 열고 텍스트를 선택하거나 로컬 재생 가능한 비디오를 가져온 뒤 방 생성 전에 화면 수와 레이아웃을 설정하세요.
  2. iPhone 또는 iPad 호스트도 한 화면입니다. 기기 자체 재생은 1개, 여러 기기 재생은 모든 참여 기기를 합산하세요.
  3. 방을 만들고 다른 기기에서 Join as Display를 열어 가까운 방에 참가하세요. 필요한 경우 호스트에서 요청을 승인하세요.
  4. 각 화면 위치와 가로·세로 방향을 배정하고 실제 배치에 맞게 간격과 자르기를 보정하세요. 매핑을 바꾸면 기기를 옮기지 않고 표시 내용을 바꿀 수 있습니다.
  5. 참가와 비디오 전송 완료를 기다린 뒤 재생하세요. 호스트는 디스플레이 페이지로 전환됩니다. 재생 화면을 탭해 탐색을 표시하고 Host Room으로 돌아가 일시 정지하거나 방을 닫으세요.

한 Mac에서 여러 창 사용

네이티브 Mac Host Controller는 방을 자동으로 알립니다. 파일 > 새로운 창으로 두 번째 창을 열고 Display Node를 선택해 참가하세요. 디스플레이 창이 하나면 1 x 1을 사용하세요. 제어 창은 화면 타일이 아니며 참가한 각 Display Node 창이 한 화면입니다. 참가를 승인하고 도구 막대의 Play를 누르세요. 실제 다른 기기도 참가할 수 있습니다.

Apple TV에서 참가

Apple TV는 디스플레이 수신기이며 호스트가 아닙니다. iPhone, iPad 또는 Mac에서 방을 열어 두고 Apple TV에서 참가한 뒤 승인하고 호스트에서 재생하세요. iPhone 또는 iPad와 Apple TV는 2개 화면, Mac 제어 창에 Apple TV만 디스플레이로 연결하면 1 x 1을 사용하세요.

질문과 문제 해결

AirPlay나 데스크톱 미러링인가요?

아니요. 선택한 텍스트나 비디오를 배정된 화면 영역에 나눕니다. 전체 데스크톱, 다른 앱이나 보호된 스트리밍 서비스는 미러링하지 않습니다.

계정이나 인터넷이 필요한가요?

로컬 방에는 계정이나 클라우드가 필요하지 않습니다. 각 기기에 앱을 설치하고 가까이 두며 로컬 네트워크 접근을 허용하세요. 같은 Wi-Fi를 권장하며 기기 격리 설정은 방 검색을 막을 수 있습니다.

크기와 방향이 다른 화면을 조합할 수 있나요?

예. 각 화면에 위치와 방향을 배정하고 실제 배치에 맞게 간격과 자르기를 보정하세요. 화면 매핑으로 기기를 옮기지 않고 콘텐츠 배정을 바꿀 수 있습니다.

방이 안 보이거나 비디오가 비어 있나요?

방을 열어 두고 네트워크 권한과 기기 격리를 확인하며 호스트에서 참가를 승인하세요. 로컬 재생 가능한 비디오를 사용하고 전송 완료를 기다리세요.

프레임 단위 동기화를 보장하나요?

공유 타임라인으로 재생을 맞추지만 하드웨어 프레임 잠금은 보장하지 않습니다. 기기, 비디오, 네트워크에 따라 달라집니다. 행사 전에 실제 구성을 시험하고 보정하세요. 레이아웃 제한은 검증된 동시 연결 용량을 뜻하지 않습니다.
