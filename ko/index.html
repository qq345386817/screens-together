임시 디스플레이 월을 위해 설계되었습니다.

ScreensTogether는 기기 배치, 타일 할당, 재생 동기화에 집중합니다. 로컬 룸의 기본 흐름에는 계정이 필요하지 않습니다.

호스트가 캔버스 제어

텍스트나 비디오를 선택하고 레이아웃과 화면 간격을 조정한 뒤 한 기기에서 재생을 시작합니다.

각 기기가 하나의 타일 표시

참가한 디스플레이는 할당을 받고 전체 그림 중 자신의 부분만 표시합니다.

데모 이상으로 유용

부스 안내, 수업 화면, 테이블 디스플레이, 창문 메시지, 이벤트 비주얼을 빠르게 만들 수 있습니다.

하나의 앱, 서로 다른 역할

무료 앱입니다. 제공 여부는 App Store에서 확인하세요.

iPhone / iPad

iPhone 또는 iPad 호스트도 한 화면입니다. 기기 자체 재생은 1개, 여러 기기 재생은 모든 참여 기기를 합산하세요.

macOS

네이티브 Mac Host Controller는 방을 자동으로 알립니다. 파일 > 새로운 창으로 두 번째 창을 열고 Display Node를 선택해 참가하세요. 디스플레이 창이 하나면 1 x 1을 사용하세요. 제어 창은 화면 타일이 아니며 참가한 각 Display Node 창이 한 화면입니다. 참가를 승인하고 Live Controls의 Play를 누르세요. 실제 다른 기기도 참가할 수 있습니다.

Apple TV

Apple TV는 디스플레이 수신기이며 호스트가 아닙니다. iPhone, iPad 또는 Mac에서 방을 열어 두고 Apple TV에서 참가한 뒤 승인하고 호스트에서 재생하세요. iPhone 또는 iPad와 Apple TV는 2개 화면, Mac 제어 창에 Apple TV만 디스플레이로 연결하면 1 x 1을 사용하세요.
